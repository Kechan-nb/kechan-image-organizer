# Kechan Image Organizer

WordPress plugin to organize inline images using a virtual media taxonomy and restore removed images to saved markers.

## GitHub Releases

Publish a stable release with a tag such as `v1.1.0` and attach an asset named exactly `kechan-image-organizer.zip`. The asset must contain a top-level `kechan-image-organizer/` folder with `kechan-image-organizer.php` and `readme.txt` inside. WordPress checks the latest stable release for updates.

## Security notes

- Do not commit passwords, WordPress credentials, API tokens, or other secrets.
- Use a backup and test on a staging site before removing images from production posts.
- GitHub releases distribute updates; they do not automatically discover or fix vulnerabilities.
